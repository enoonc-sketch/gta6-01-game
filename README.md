CINDER BAY is an original open-world crime game that plays in the browser: you are Rhea Calloway, back in a sun-soaked port city and in debt to Old Tomas, working six story jobs to get clear. Roam on foot or by car — steal cars, dodge traffic and pedestrians, fight, outrun the wanted-star police, follow the gold marker to jobs and courier runs, and hunt 20 hidden lucky shells, with a minimap HUD and on-device saves, all from static files with no network needed.

## Run it

```sh
node serve.ts
```
